# Hand meshes

Skinned Quest-style hands from [`@webxr-input-profiles/assets`](https://www.npmjs.com/package/@webxr-input-profiles/assets)
`generic-hand` (v1.0.16, MIT), the Oculus-provided WebXR hand meshes. Same files as the Hexalt project.
Joint names match the WebXR Hand API (`wrist`, `thumb-metacarpal`, `index-finger-tip`, ...).
